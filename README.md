# 银行反欺诈告警关系分析与案件调查平台

基于 React、Mantine、Redux Toolkit、RTK Query、React Router、React Flow、Vite 和 TypeScript 实现的中文前端项目。项目使用浏览器 `localStorage` 模拟服务端数据库，不依赖外部后端即可运行。

## 功能

- 告警中心：关键词、风险等级、状态和渠道组合筛选，批量关联案件或排除。
- 案件工作台：案件列表、风险状态和调查工作量概览。
- 共享实体：设备、IP 跨案件共用一份实体记录（版本号、修订历史、核验状态），图谱节点按实体引用；证据、关系边与结论仍只归各自案件。
- 结论失效联动：共享实体属性一旦更新，所有引用案件的未终结结论立即标记失效，重新核对后才能恢复复核或关闭案件；已关闭案件自动回到待补证。
- 并发冲突处理：两个窗口同时保存同一实体时按版本做三方对比，无冲突字段自动合并；冲突字段逐项选择保留方，对方已核验的字段锁定不可覆盖。
- 写入恢复：每次写入保留最近完整版本备份，写入失败自动回滚并可基于完整版本重试；主数据损坏时从备份恢复。
- 旧数据迁移：首次打开旧数据时按设备号 / IP 自动归并重复节点，属性冲突无法确认的列入待核清单，由调查员确认归并或保留独立节点。
- 关系图谱：账户、设备、IP、商户关系布局，节点拖动持久化，共享实体节点显示统一版本徽标。
- 联动时间轴：交易、告警和证据按时间排序，实体相关事件标注共享实体版本，点击后高亮对应关系。
- 证据台账：来源、发生时间、提交人、附件标识、证据强度和版本记录。
- 结论版本：保存草稿或提交复核，支持通过、退回补证和案件状态流转。
- 审计报告：操作人和时间不可变留痕，实体操作记录实体版本；支持 JSON（含实体快照）、CSV 导出及演示数据重置。

## 技术栈

- React 19 + TypeScript
- Mantine 9
- Redux Toolkit + RTK Query
- React Router
- React Flow
- Vite

## 运行

```bash
npm install
npm run dev
```

访问 `http://localhost:18458`。

## 构建

```bash
npm run build
npm run preview
```

`npm run build` 会先执行严格 TypeScript 检查，再生成 Vite 生产构建。

## 冒烟测试

```bash
npm run test:smoke
```

覆盖三层共 50+ 项断言：存储层（迁移归并、待核清单、写入失败恢复、备份恢复）、API 层（结论失效/恢复、并发冲突与核验锁定、待核归并）、页面层（jsdom 挂载案件页 / 时间轴 / 审计页 / 工作台，含双窗口冲突弹窗全流程）。

## 数据说明

首次打开时会将演示案件写入 `localStorage`（schema v2）。旧版 v1 数据在首次读取时自动迁移：设备 / IP 节点按设备号或 IP 归并为共享实体，属性冲突的列入待核清单。后续新增证据、结论、关系节点、实体修改和状态流转会持久化到同一浏览器存储，并同步维护一份最近完整版本备份用于失败恢复；“审计与报告”页面可以重置全部演示数据。

### 演示写入失败恢复

在浏览器控制台执行 `window.__mockFailNextWrite = true` 可让下一次写入模拟失败：系统会自动回滚到最近一个完整版本，界面提示后可基于该版本重试。

### 演示双窗口并发

打开两个浏览器窗口进入同一案件，先后编辑同一共享实体并保存：后保存的一方会收到字段冲突框，逐项选择保留方后才会写入；若对方已点“标记核验”，被核验字段锁定为对方版本。
