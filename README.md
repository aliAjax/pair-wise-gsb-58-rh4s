# 银行反欺诈告警关系分析与案件调查平台

基于 React、Mantine、Redux Toolkit、RTK Query、React Router、React Flow、Vite 和 TypeScript 实现的中文前端项目。项目使用浏览器 `localStorage` 模拟服务端数据库，不依赖外部后端即可运行。

## 功能

- 告警中心：关键词、风险等级、状态和渠道组合筛选，批量关联案件或排除。
- 案件工作台：案件列表、风险状态和调查工作量概览。
- 共享实体记录：设备、IP、账户、商户全库唯一一份，各案件图谱只保存布局；证据与结论仍归各自案件。
- 实体版本联动：实体属性更新即提升版本，受影响案件的旧结论自动失效，重新核对后才能恢复并复核通过。
- 并发冲突处理：两个窗口同时保存同一实体时按字段三方合并，冲突字段需逐项裁决；他人已核验的字段默认不可覆盖。
- 写入恢复：每次提交先落完整快照到写入日志，主库写入失败后下次打开自动从完整版本恢复。
- 旧数据迁移：首次打开按设备号 / IP 归并各案重复节点与关系，无法确认的列入待核列表，可在概览页确认归并或排除。
- 关系图谱：账户、设备、IP、商户关系布局，节点拖动持久化，节点与关系展示版本号和核验状态。
- 联动时间轴：交易、告警和证据按时间排序，显示共享关系版本，点击后高亮对应关系。
- 证据台账：来源、发生时间、提交人、附件标识、证据强度和版本记录。
- 结论版本：保存草稿或提交复核，支持通过、退回补证和案件状态流转；结论携带实体版本快照。
- 审计报告：操作人和时间不可变留痕，共享实体版本台账与案件页同源，支持 JSON、CSV 导出及演示数据重置。

## 技术栈

- React 19 + TypeScript
- Mantine 9
- Redux Toolkit + RTK Query
- React Router
- React Flow
- Vite

## 运行

```bash
npm install
npm run dev
```

访问 `http://localhost:18458`。

## 构建

```bash
npm run build
npm run preview
```

`npm run build` 会先执行严格 TypeScript 检查，再生成 Vite 生产构建。

## 数据说明

首次打开时会将旧版（v1）演示数据写入 `localStorage`，读取时自动迁移为共享实体模式（schema v2）：重复节点按设备号 / IP 归并，无法确认的进入待核列表。后续新增证据、结论、共享实体更新、关系核验和状态流转会持久化到同一浏览器存储；每次写入先落完整快照到日志键，主键写入失败可在下次打开时恢复。多个浏览器窗口打开同一案件可演示并发冲突：后到的一方会收到字段级冲突并要求逐项裁决。“审计与报告”页面可以重置全部演示数据（重置后重新走迁移流程）。
